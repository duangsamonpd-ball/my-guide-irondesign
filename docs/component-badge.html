Badge

A small, non-interactive label that conveys status, category or count. Six semantic colours map straight to the success / warning / danger / info / important / neutral tokens.

Subtle vs Solid
Subtle (tinted background) is the default for in-page status. Solid is for higher emphasis — use sparingly.

Code
<!-- colours: success / warning / danger / info / important / neutral -->
<span class="badge badge--success"><span class="bdot"></span>Active</span>
<span class="badge badge--warning">Pending</span>
<span class="badge badge--important">Important</span>

<!-- solid + pill -->
<span class="badge solid badge--info">Beta</span>
<span class="badge badge--neutral pill">Draft</span>

<!-- dark mode — wrap in a .dark ancestor, badges are unchanged -->
<div class="dark">
  <span class="badge badge--success">Active</span>
</div>

<!-- small size -->
<span class="badge badge--info sm">Small</span>
.badge {        /* default shape matches Figma: rounded-sm, not a pill */
  font-size: var(--font-size-badge); font-weight: var(--fw-badge);
  border-radius: var(--rounded-sm); padding: 5px 10px;
}
.badge.pill { border-radius: var(--rounded-full); }
.badge--success {        /* subtle — semantic tokens, so dark mode is a free swap */
  background: var(--color-success-subtle);
  color: var(--color-success-strong);
}
.badge.solid.badge--success { background: var(--color-success); color: var(--color-text-on-color-badge-solid-inverse); }
/* solid picks its label per intent, not per theme — white on the light
   fills (success/warning/info) is 2.17/1.99/3.25 and fails WCAG AA */

/* dark mode lives in the theme, not the component: */
.dark {
  --color-success-subtle: var(--color-success-subtle-dark);  /* #345F50 */
  --color-success-strong: var(--color-success-strong-dark);  /* #B1E0D0 */
}
.badge.sm { font-size: var(--font-size-badge-sm); padding: 3px 8px; }
Guidelines
✓ Do
Paid Overdue Archived
  • Match colour to meaning (green = good, red = error).
  • Keep labels to 1–2 words.
  • Use subtle by default; reserve solid for emphasis.
  • Use .dark on dark backgrounds instead of the light-mode subtle fill.
✗ Don't
Click here to retry now
  • Don't make badges clickable — that's a Button or link.
  • Don't write sentences inside a badge.
  • Don't pick colours for looks; pick by intent token.
