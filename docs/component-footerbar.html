Footer Bar

Deviations from Figma
Four things in the design file that the code deliberately does not copy. Each needs a fix on the Figma side, not here.
  • Gotham in a Montserrat system. The review scores, “Join Iron Slack” and “Every Iron Suite Donates” are set in Gotham with no variable bound. They are Montserrat here.
  • A raw Light Gray. “Join Iron Slack” paints a Figma style rather than a variable; it uses --color-text-on-color-body here, like every other secondary line.
  • A gap bound to the wrong step. The brand lockup’s gap binds spacing-xl but resolves to 6px — off the scale entirely, which goes 4 then 8.
  • An opacity that does nothing. Capterra’s stars bind opacity-30 and resolve to 1. The exported artwork carries its own greys, so nothing extra is applied here.
Not built yet
Figma’s footer-lg set has three variants and there are separate footer-md (768) and footer-sm (375) symbols. Only Default at lg is implemented.
  • Free tools version — adds a Free tools item with a caret to the menu row.
  • Free tool open — expands a three-column panel (PDF Converters / PDF Editors / Others) under the menu.
  • md and sm — the tablet and mobile layouts, both drawn in Figma and both unimplemented.
