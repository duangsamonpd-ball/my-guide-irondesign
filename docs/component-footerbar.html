Deviations from Figma
What the code does not copy from the design file, and why. Most of these want a fix on the Figma side rather than here; the two marked settled are decisions already taken.
  • Gotham in a Montserrat system. The review scores, “Join Iron Slack” and “Every Iron Suite Donates” are set in Gotham with no variable bound. They are Montserrat here.
  • A raw Light Gray. “Join Iron Slack” paints a Figma style rather than a variable; it uses --color-text-on-color-body here, like every other secondary line.
  • A gap bound to the wrong step. The brand lockup’s gap binds spacing-xl but resolves to 6px — off the scale entirely, which goes 4 then 8.
  • Two ways to say 30%. Both star rows are white at 30% — the empty state, which is why they read as grey. G2 sets it on each of the five stars, Capterra sets it on the group. Same result, stated two different ways.
  • The two variants disagree about the Slack row. Default places a 16px icon in a 20px row at leading 20; Free tools version places a 24px icon in a 24px row at leading 18. Settled 2026-08-02: Default is correct, so 16px is used in both regions and the Free tools variant is the one to correct in Figma.
  • A divider is missing between Free Tools and Webinars. Every other pair of menu items has one; that node is hidden in both variants and keeps stale coordinates. Settled 2026-08-02: draw it — the hidden node is a leftover, and Figma is the side that needs the fix.
Not built yet
Figma’s footer-lg set has three variants and there are separate footer-md (768) and footer-sm (375) symbols. Default and Free tools version are implemented — both are above.
  • Free tool open — expands a three-column panel (PDF Converters / PDF Editors / Others) under the menu. The only one of the three that needs new markup rather than a prop.
  • md and sm — the tablet and mobile layouts, both drawn in Figma and both unimplemented.
