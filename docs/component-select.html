Select

A trigger that opens a menu to pick one value from a longer list — countries, plans, statuses. Click the trigger below to open it; the chevron flips and the chosen option is ticked.

Code
<!-- add "error" or "disabled" to the outer .sel to switch state -->
<!-- WAI-ARIA "select only" listbox pattern — ids below just need to be unique per instance -->
<div class="sel">
  <label id="country-label">Country</label>
  <button class="sel-trigger" id="country-trigger"
    aria-haspopup="listbox" aria-expanded="false"
    aria-controls="country-listbox" aria-labelledby="country-label country-trigger">
    <span>United States</span>
    <span class="chev" aria-hidden="true">▾</span>
  </button>
  <div class="sel-menu" id="country-listbox" role="listbox" tabindex="-1">
    <div class="sel-opt selected" role="option" aria-selected="true">United States <span class="ck" aria-hidden="true"><svg>…</svg></span></div>  <!-- Font Awesome check -->
    <div class="sel-opt" role="option" aria-selected="false">Thailand</div>
    <div class="sel-opt" role="option" aria-selected="false">Japan</div>
  </div>
</div>
<!-- keyboard: ↑/↓ moves aria-activedescendant on the listbox, Enter/Space commits, Esc closes -->
.sel-trigger {
  width: 100%; height: var(--size-input);
  border: 1.5px solid var(--color-border);
  border-radius: var(--rounded-md);
}
.sel.open .sel-trigger { border-color: var(--color-secondary); box-shadow: var(--shadow-focus-blue); }
.sel.error .sel-trigger { border-color: var(--color-danger); }
.sel.disabled .sel-trigger { background: var(--color-bg-shade); color: var(--color-text-disabled); cursor: not-allowed; }
.sel-menu { box-shadow: var(--shadow-float); border-radius: var(--rounded-lg); }
.sel-opt.selected { background: var(--color-bg-card-alt); color: var(--color-secondary); }
.sel-opt .ck { opacity: 0; }  .sel-opt.selected .ck { opacity: 1; }   /* Font Awesome Free Solid "check" SVG, currentColor fill — shown only on selected */
Guidelines
✓ Do
  • Use when there are more than ~6 options.
  • Always show the current value in the trigger.
  • Keep option labels short and scannable.
  • The selected checkmark is a Font Awesome Free Solid SVG, inlined with fill="currentColor".
  • Ships as an accessible listbox — role="listbox"/"option", aria-expanded, aria-activedescendant, and full arrow-key/Home/End/Enter/Esc support.
✗ Don't
  • Don't use a Select for 2–3 options — use Radio.
  • Don't open the menu without a visible chevron cue.
  • Don't hard-code the menu shadow; use --shadow-float.
